Kostenlos · ohne Werbung

Das Hausaufgabenheft für deine ganze Klasse

Einer trägt ein, alle wissen Bescheid – und jede und jeder hakt für sich ab. Mitglieder brauchen weder E-Mail-Adresse noch Passwort: Code eingeben, Namen eingeben, fertig.

Klasse beitreten Heft für deine Klasse anlegen

Läuft im Browser auf iPhone, Android und Computer – und lässt sich wie eine App auf den Home-Bildschirm legen.

So funktioniert’s

  1. Klasse anlegen

    Eine Person aus der Klasse legt das Heft an und wird Admin. Nur Admins melden sich mit E-Mail-Adresse an – per Code, ohne Passwort.

  2. Code teilen

    Den Einladungscode oder -link in die Klassengruppe schicken. Er gilt standardmäßig 7 Tage und lässt sich jederzeit ungültig machen.

  3. Alle sind dabei

    Wer den Code hat, gibt einen Namen ein – auch ein Spitzname geht. Das Gerät bleibt angemeldet.

Was Abgehakt kann

  • Alles bis zur Abgabe im Blick

    Die Tagesansicht zeigt, was ab heute ansteht – sortiert nach Abgabetag, mit „bis morgen“ oder „in 3 Tagen“. Wochenenden werden übersprungen, Schulaufgaben und andere Termine stehen gesammelt oben.

  • Jede und jeder hakt für sich ab

    Dein Häkchen gehört dir. Ob andere sehen, was du erledigt hast, entscheidest du selbst – standardmäßig niemand.

  • Private Aufgaben und Notizen

    „Vokabeln für den Test lernen“ nur für dich, dazu eine Notiz an jeder Aufgabe. Das sieht niemand außer dir – auch keine Admins.

  • Erinnert dich rechtzeitig

    Auf Wunsch am Vorabend: was für morgen noch offen ist und welche Schulaufgaben anstehen. Du wählst die Uhrzeit – oder schaltest es ganz aus.

  • Auch ohne Internet

    Im Funkloch oder ohne WLAN in der Schule: Abhaken und Eintragen klappt trotzdem – Abgehakt schickt alles nach, sobald wieder Netz da ist.

  • Die Klasse regelt sich selbst

    Admins legen fest, wer eintragen darf, laden Nachzügler ein und entfernen Mitglieder. Unpassende Einträge können gemeldet werden.

  • Mehrere Klassen, mehrere Geräte

    Mehrere Klassen auf einem Gerät, oben umschaltbar. Und mit einem Code ist man auf dem neuen Handy wieder dieselbe Person.

So wenig Daten wie möglich

  • Keine E-Mail-Adresse für Mitglieder – ein Name oder Spitzname reicht
  • Kein Tracking, keine Werbung, keine Analyse-Tools, keine fremden Skripte
  • Die Datenbank liegt in der EU
  • Wir sehen uns die Hefte nicht an – nur einzelne Einträge, die gemeldet werden
  • Wer die Klasse verlässt, dessen Häkchen und Notizen werden gelöscht
  • Klassen, die ein Jahr nicht genutzt werden, werden automatisch gelöscht

Alle Einzelheiten stehen in der Datenschutzerklärung.

Häufige Fragen

Was kostet Abgehakt?

Nichts. Abgehakt ist ein privates, nicht-kommerzielles Projekt: kostenlos, ohne Werbung, ohne bezahlte Zusatzfunktionen.

Muss ich eine App installieren?

Nein. Abgehakt läuft im Browser. Wer möchte, legt es auf den Home-Bildschirm – dann startet es wie eine App, direkt im Heft. Die App zeigt nach dem Beitreten, wie das auf deinem Gerät geht.

Wer kann Hausaufgaben für die Klasse eintragen?

Admins und alle, denen ein Admin das Recht „Eintragende“ gibt. Alle anderen können Aufgaben nur für sich selbst anlegen.

Sehen andere, was ich schon erledigt habe?

Nur wenn du es willst. In deinen Einstellungen (Zahnrad oben im Heft) legst du fest: niemand (Standard), alle oder bestimmte Personen.

Ich habe ein neues Handy – ist alles weg?

Nein. Auf dem alten Gerät unter „Einstellungen → Weiteres Gerät anmelden“ einen Code erzeugen oder einen Admin um einen persönlichen Code bitten. Damit bist du auf dem neuen Gerät wieder dieselbe Person – mit allen Häkchen und Notizen.

Was passiert mit unserem Heft am Schuljahresende?

Es bleibt bestehen, solange es genutzt wird. Admins können die Klasse jederzeit löschen. Wird ein Heft ein Jahr lang nicht genutzt, wird es automatisch gelöscht – die Admins bekommen vorher eine E-Mail.
